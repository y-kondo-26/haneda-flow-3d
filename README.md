# 羽田フローツイン

羽田空港をモデルにしたターミナルで、旅客の流れと手荷物の流れを AI による運用最適化で効率化する様子を、three.js の 3D モデルとアニメーションで見せるデモです。

- 公開ページ: https://y-kondo-26.github.io/haneda-flow-3d/
- 同じ便スケジュールで「従来運用」と「AI 最適化」の2つのシミュレーションを同時に動かし、KPI は両方の計測値から計算します。

## 注意

画面の数値は架空の設定に基づくシミュレーションの値です。羽田空港の実際のレイアウト・運用データではありません。空港会社・航空会社とは関係がありません。

## ビルド

`src/` の部品をファイル名の順につないで1つの HTML にします。

```bash
./build.sh
```

- `haneda-flow.html`: Artifact 用の本文（doctype・head を含まない）
- `docs/index.html`: GitHub Pages で配信する完全な HTML
